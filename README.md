1. EV-ANALYSIS DASHBOARD: A dynamic Interactive Data Visualization tool built to explore Electric Vehicle population data around Uinted States wide-focussing on regional comparisions etc.
2. Short Description: this project focuses on building an electric vehicle (EV) population analysis dashboard thet visualizes and analyzes data reklated to EV registrations , growth trends, and adoption across regions. The dashboard helps users understand patterns in EV usage, compare vehivcle types  (BEV, PEHV,CAFV) and track key performances indicators such as total EVs yearly growth and regionall distribution. It provides an interactive and data driven view of the EV market to support better planning and making
3. Tech Stack: PowerBI desktop - Main data visualisation platform used for report creation
               PowerQuery - Data transformation and cleaning layer for reshaping and preapring the data
               DAX - used for calculated measures, dynamic, visuals, and conditional logic                                                                                                      File format - pbix for development and png for dashboard previews
4. Data Source - Kaggle.com
5. Features/Highlights:
 Interactive Visuals
Dynamic charts, slicers, and filters allow users to explore the data from multiple perspectives.
 Geographical Analysis:
Maps or geographical visuals showcase EV adoption or charging station deployment across regions.
 Time-Series Insights:
Line charts to visualize EV growth trends over months/years.
 Comparative Metrics:
Side-by-side comparisons of EV models or manufacturers using bar or pie charts.
 KPIs & Summary Cards:
Top-level metrics like total EVs sold, average range, top brands by share, etc.
 Drill-Down Capability:
Users can drill down to detailed insights from summary level metrics.
User-Friendly Experience: Clean layout with visually appealing and easy-to-read visuals.
Real-Time Insights: Dashboard refresh allows up-to-date analysis (if connected to live data).
Data Storytelling: Combines visuals and insights to help users understand market trends and performance.
Custom Report Themes: Consistent brand colors/icons enhance readability and aesthetics.
Performance Optimized: Designed for fast rendering and smooth navigation.
